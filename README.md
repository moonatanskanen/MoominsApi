# MoominsApi
This project was created as an exam assignment during my first API course. The goal was to build a simple REST API with a Moomin themed application as the subject.
The API allows users to retrieve, add and delete Moomin characters. Moomins can be searched by name, or specific Moomin can be found using its number. The API also handles different HTTP status codes depending on the result of the request.
The project also includes a simple console client that communicates with the API using HttpClient and JSON.

During this assignment and the course, I learned the basics of building and using REST APIs. For example, I gained experience with creating API controllers, using different requests, handling HTTP status codes and using HttpClient to communicate with an API.
My course grade was 4/5.
